## 飞书配置

名单目标：用户指定的 https://ycnf2mmv4sns.feishu.cn/wiki/X0mywEWiripVUxk0sN0caVbwnmg ，表 ID `tblgE64FFh8kWYbJ`。

在飞书开放平台使用企业自建应用，为它配置新增多维表格记录、读取字段结构所需权限，并把它添加为该多维表格具有写权限的协作者。若让程序从 Wiki 链接解析 base token，还需读取知识库节点权限及访问该节点；也可直接将真实 base app_token 写入 `EVENT_FEISHU_APP_TOKEN`。不要把 Wiki 链接末尾 token 当作 app_token。

服务端配置见 `site/.env.event.example`。App Secret 只进入服务器环境变量或 GitHub Actions Secrets，不发送给浏览器，不写进 HTML、Git 或本交付包。现有官网 `.github/workflows/deploy-cn.yml` 会重写 `.env.production`，因此上线时必须把 EVENT_* 配置接入部署流程或可靠的外部环境配置；只手动改一次服务器 `.env.production` 会被下一次发布覆盖。中国站发布分支会同步更新部署流程，功能 PR 不包含中国站专属凭证配置。

字段需采用以下名称与类型（2026-10-26 已确认全部字段，申请状态、M授权、T授权已创建）：

| 飞书字段 | 类型 | 写入内容 |
|---|---|---|
| 您的姓名 | 文本 | 姓名，必填 |
| 您的手机号 | 文本或电话 | 标准化后的 11 位大陆手机号 |
| 您的企业 | 文本 | 公司，必填 |
| 您的职位 | 文本 | 职位，必填 |
| 邀请人 | 文本 | 选填 |
| 渠道 | 文本或单选 | 固定“官网”；单选需已有该选项 |
| 申请状态 | 文本或单选 | 固定“待审核”；单选需已有该选项 |
| M授权 | 单选（是/否） | 对应 MindsLeap 隐私政策勾选，不代表产品营销授权 |
| T授权 | 单选（是/否） | 对应腾讯云单独授权勾选 |
| 费用 | 保持原类型 | 接口省略，不填 0 |
| 销售 | 保持原类型 | 接口省略，不写人员或文本 |

请确认费用/销售没有表级默认值或自动填充规则，否则“省略”仍可能触发飞书默认值。飞书系统“提交时间”字段记录实际创建记录的时间。接口不再写入 JSON 授权记录；重试仍使用相同 `client_token` 和记录内容进行去重。

接口会预检以上必需字段，缺字段、类型不符或缺少单选值即返回 503，不创建部分记录。校验通过后使用 Feishu `client_token` UUIDv4 进行重复请求保护。只有飞书返回业务成功与记录 ID 才显示申请已提交。网络结果不确定时，访客保留页面重试可复用原请求标识；刷新页面或重新修改信息是新申请，飞书侧应按手机号人工核对重复申请，不会向访客泄露历史申请。

`T授权=是` 才能作为后续共享名单的候选；交付系统不自动向腾讯发送任何名单。撤回和实际共享前的授权复核需要运营执行。不要直接导出全表给赞助方。

## 上线步骤

1. 确认本版预览和隐私政策，尤其是活动资料 12 个月、营销资料最近互动起 24 个月/撤回即停止、处理情况记录至少 3 年、通常 15 个工作日回复权利请求等运营承诺。按实际可执行流程调整后保持版本与表单一致。
2. 在最新官网分支应用本包补丁/新增文件，只合入本次内容；不要拿稀疏开发副本覆盖服务器整个目录。
3. 在飞书添加 `申请状态`、`M授权`、`T授权`，检查五项原字段、渠道选项以及费用/销售默认值。
4. 配置服务端应用密钥和访问权限，把 `EVENT_*` 持久接入发布流程。完成接入后才设置 `EVENT_REGISTRATION_ENABLED=true`。
5. 建议按流量在 Nginx/网关补充真实客户端 IP 限流；接口已限制请求体为 16 KB，并提供单进程手机号哈希限流。避免在 access log 中记录请求体，保障日志访问权限。
6. 在已授权的测试窗口用明确标记的测试资料提交一次，并在指定表读回；确认状态待审核、渠道官网、费用销售确实为空、腾讯云可选授权可拒绝、M授权对应隐私政策为是、T授权如实记录是/否，且不再写入 JSON 授权记录。同一次请求重试不新增第二条。
7. 验证真实手机微信浏览器、官网 `/privacy`、Logo 回官网、移动悬浮入口。最后发布。关闭申请时把启用开关改回 false。

2026-10-26 经用户授权完成 M/T 单选列版本的正式飞书表联调：标记测试资料成功入表；重复请求复用同一记录；渠道官网、状态待审核、费用/销售为空、M授权为是、T授权为否均已读回确认；测试记录已删除。运营需在飞书手动审核，审核通过后由运营微信联系并邀请入群；系统不自动审核、不自动加微信、不自动拉群。

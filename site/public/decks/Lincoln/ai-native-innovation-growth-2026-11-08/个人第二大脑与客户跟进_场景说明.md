# 个人第二大脑与客户跟进：场景设计说明

## 内容来源与定位

根据 Lincoln 本次提出的分享方向编排：在“超级个体”阶段加入人脉墙、待办事件、私人图库，以及 Agent 驱动的客户跟进系统。两页是面向企业家的应用设计示例，不是某个产品的实测报告，也不是已完成的客户部署案例。

## 第 08 页：构建属于自己的第二大脑

- 人脉墙：联系人、认识的场景、沟通记录和下一次交流的话题。
- 待办事件：承诺、截止日期、状态和提醒。
- 私人图库：按场景、人物、时间和用途检索照片。

可通过统一入口连接既有联系人、任务和照片系统。关键事实需要核对，信息保留出处；私人资料与组织共享资料分开授权。图中的联系人、照片和界面均为虚构示意，不使用真实私人数据。

## 第 09 页：搭建一个 Agent 驱动的客户跟进系统

示例链路：授权接入客户询盘和沟通记录 → 整理背景与缺失信息 → 准备材料与回复草稿 → 人工确认发送 → 设定跟进时间 → 根据反馈更新客户状态和下一步。

这里以个人工作为范围。多人共享、权限分工和跨部门交接属于后续“超级组织”的讨论。不存在本次实测的节省工时或成交率数字；不把准备草稿、提醒跟进等同于自主对外承诺或自动成交。

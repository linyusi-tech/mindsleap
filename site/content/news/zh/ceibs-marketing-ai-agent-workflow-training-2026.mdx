**2026 年 6 月 10 日 | 上海 · 中欧国际工商学院**

2026 年 6 月 10 日，MindsLeap 为中欧国际工商学院（CEIBS）市场团队开展 AI Agent 工作流训练营。训练采用半天方法讲解与现场动手实操相结合的方式，让参与者不只了解生成式 AI 能做什么，也能围绕自己的市场工作，拆出可执行、可检查、可继续迭代的 AI Agent 工作流。

这次训练聚焦一个直接的问题：当市场团队已经开始使用大模型，下一步如何减少每次从头提示、反复修正的成本，把个人经验逐渐沉淀为团队可复用的工作方法？

## 从 Prompt 试错走向可复用工作流

单次 Prompt 可以帮助人完成一项任务，但企业市场工作的难点通常不在“生成一次”，而在持续保持品牌口径、证据边界、交付格式和协作节奏。训练因此没有停留在工具清单，而是从任务定义开始：明确业务目标、输入材料、执行步骤、输出标准与人工确认点。

MindsLeap 将这一过程拆成四个互相连接的部分：

- **Spec**：说明任务目标、输入、输出、边界与验收标准
- **Skill**：把某一类任务的做法沉淀为可重复调用的能力
- **Workflow**：把多个步骤、工具与人工判断编排成稳定流程
- **Memory**：让 Agent 能够调用品牌资料、历史内容与团队规则

当这四部分被写清楚，AI Agent 工作流才可能从个人技巧变成团队资产。

## 四类真实市场场景成为训练任务

本次训练围绕中欧市场工作的四类真实场景展开：品牌内容记忆、官网 AI 与 GEO、市场监测，以及内容与视频生产。参与者以实际资料和工作任务为输入，在现场拆解 Agent 的职责、上下文和输出要求。

![中欧商学院市场团队在现场围绕 AI 原生市场部门与工作方式展开实操](/images/news/ceibs-marketing-ai-agent-workflow-training-2026-workshop.jpg)

在品牌内容记忆场景中，重点是如何把品牌资料、已有文章、活动信息和表达规范整理成 Agent 可检索的长期 Context；在官网 AI 与 GEO 场景中，重点是让网站信息更便于搜索引擎和 AI 模型理解、引用；市场监测场景关注信息来源、筛选规则和周报结构；内容与视频场景则把选题、资料整理、初稿、审核和渠道适配串成一条生产流程。

这些场景共同说明：AI 进入市场部门，不只是增加一个内容生成工具，而是重新设计信息如何进入、判断如何发生、成果如何被审核和复用。

## Spec、Skill、Workflow 与 Memory 如何协同

现场实操要求参与者先写清 Spec，再把成熟步骤沉淀为 Skill，并通过 Workflow 连接资料读取、内容生成、事实核查和人工审核。Memory 则为整个流程提供稳定的品牌背景和历史上下文。

例如，一个市场监测 Agent 不能只收到“看看行业最近有什么新闻”的提示。它还需要知道关注范围、可信来源、排除条件、分类方法、输出频率和升级规则。一个内容 Agent 也不能只追求流畅表达，还要理解品牌定位、可引用证据、禁用表述和最终发布渠道。

## 从个人效率走向团队操作系统

![MindsLeap 讲师与中欧商学院市场团队讨论 AI Agent 工作流的设计与边界](/images/news/ceibs-marketing-ai-agent-workflow-training-2026-discussion.jpg)

训练中的关键转变，是把注意力从“谁更会提问”转向“团队如何共同维护一套做事方法”。个人 Prompt 往往只存在于聊天记录里，而经过整理的 Spec、Skill、Workflow 与 Memory，可以被团队共同审核、复用和更新。

这也为市场组织使用 AI 建立了更清晰的责任边界：AI 负责资料整理、初稿生成、格式转换和重复执行，人继续负责目标设定、事实确认、品牌判断与最终发布。工作流的价值不是取消人的判断，而是把判断放到最关键的位置。

## 常见问题

### 这次是工具培训还是工作流训练？

核心是工作流训练。工具用于完成任务，但训练重点是如何定义 Spec、沉淀 Skill、编排 Workflow，并用 Memory 提供稳定上下文。

### 为什么市场团队需要建立品牌 Memory？

因为通用模型并不了解企业自己的历史内容、表达规范和证据边界。品牌 Memory 可以为不同 Agent 提供一致的背景，减少口径漂移。

### AI Agent 工作流能直接自动发布内容吗？

是否自动发布取决于任务风险和企业规则。对外内容通常应保留事实核查、品牌审核和最终确认等人工节点。

### MindsLeap 的企业 AI 培训如何设计？

通常从团队真实业务场景出发，结合方法讲解、现场实操、成果评审和后续迭代，把 AI 认知转化为可继续使用的工作流资产。
